# Manual de usuario "Software de monitoreo"

### Cómo usar este Software.

#### Para ello sigue estos paso.

- Paso 1: Clonar el repositorio

Clona el repositoio de github a tu computadora, cuando hallas clonado, cambia a la rama prueba; para ello ingresa una terminal e ingresa al directorio

Si estas en Linux

```bash
nombredeldispoitivo@linux-modelo:~$ /home/directorio-donde-lo-clonaste/
```

Si estasn en windows

```ps
PS C:\Users\nombre-del-usuario\Directorio-donde-clonaste-el-repositorio
```

- Paso 2: Inicializar el servidor y el cliente.

Una vez que tengas ya el repositorio descargado, tendras que inicializar el servidor. Para ello, en tu terminal, deberas colocar el siguiente comando:

```bash
python3 servidor.py
```

### o

```ps
python servidor.py
```

Dependiendo de tu sistema.

Para poder inicializar el codigo de cliente, deberas de hacer lo mismo pero cambiando el nombre del archivo, ya no se llamara "servidor" si no "cliente".

- Paso 3: Abrir el Dashboard

Una vez que tengas el servidor y el cliente ya inicializados, lo que tendras que hacer es abrir el Dashboard, solo da clic al archivo "Index.html" y se abrira la pagina web. Y ya podras acceder al softwere, podras bloquear paginas web, el ping, apagar la computadora, y monitorear la computadora.
